# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security vulnerabilities as public issues.

Use GitHub private vulnerability reporting if it is enabled for this repository.

Include:

- affected StaghojQR version
- a minimal reproduction
- expected security impact
- browser/environment
- suggested mitigation, if known

## Privacy model

StaghojQR generates QR codes locally.

The core library does not need to send the QR payload to a remote QR service.

## Application responsibility

A QR code can encode an unsafe URL or other malicious content. Applications using StaghojQR should validate or constrain untrusted input according to their own threat model.

`render()` inserts SVG generated by StaghojQR into the selected element. The accessible SVG title is HTML-escaped by the library.
