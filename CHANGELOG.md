# Changelog

All notable changes to StaghojQR will be documented here.

## [2.0.1] - 2026-09-27

### Added

- Initial public StaghojQR release
- Fixed QR Version 6 / H byte-mode engine
- SVG rendering
- PNG and Canvas rendering
- Browser download helpers
- qrcode.js-style compatibility helper
- Optional responsive CSS
- Public documentation and examples
