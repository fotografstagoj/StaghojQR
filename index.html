Small QR engine. No external QR service.

StaghojQR is a dependency-free JavaScript QR code engine for websites and web applications. It generates QR codes locally in the browser and supports SVG, PNG and Canvas output.

Installation

Self-hosted

Download the release or copy the files from dist/ into your own project.

<link rel="stylesheet" href="/assets/staghojqr.css">
<script src="/assets/staghojqr.js"></script>

<div id="qr" class="staghojqr staghojqr--md"></div>

<script>
StaghojQR.render(
  document.getElementById('qr'),
  'https://example.com',
  { title: 'Example QR code' }
);
</script>

CDN with jsDelivr

Because the project is public on GitHub, jsDelivr can serve a tagged release directly. Pin the version in production instead of using an unversioned URL.

<link rel="stylesheet"
 href="https://cdn.jsdelivr.net/gh/fotografstagoj/StaghojQR@v2.0.1/dist/staghojqr.css">

<script
 src="https://cdn.jsdelivr.net/gh/fotografstagoj/StaghojQR@v2.0.1/dist/staghojqr.js"></script>

Then use the same JavaScript API as with self-hosting.

Recommended: use an exact tag such as v2.0.1 so a future update does not unexpectedly change your production site.

Styling with CSS

The QR engine itself does not require CSS. The included stylesheet gives you responsive wrappers and three ready-made sizes. You can also add your own classes.

Built-in size classes

<div class="staghojqr staghojqr--sm"></div>
<div class="staghojqr staghojqr--md"></div>
<div class="staghojqr staghojqr--lg"></div>

Custom width and container style

.my-qr {
  width: 220px;
  padding: 10px;
  border: 2px solid #111827;
  border-radius: 16px;
  background: white;
}

Changing SVG colors

The generated SVG uses a background rectangle and a module path. CSS can override their fill values.

.brand-qr svg rect {
  fill: #fff !important;
}

.brand-qr svg path {
  fill: #0f172a !important;
}
Keep strong foreground/background contrast. Decorative color choices can reduce scanner reliability.

Common API examples

Render

StaghojQR.render(
  element,
  'https://example.com',
  { title: 'QR code' }
);

Download SVG

StaghojQR.downloadSvg(
  'https://example.com',
  'example.svg'
);

Download PNG

StaghojQR.downloadPng(
  'https://example.com',
  'example.png',
  1024
);

qrcode.js-style compatibility

Load the compatibility helper after the main engine:

<script src="dist/staghojqr.js"></script>
<script src="dist/staghojqr-compat.js"></script>

<script>
new QRCode(document.getElementById('qr'), {
  text: 'https://example.com',
  title: 'Example QR code'
});
</script>
